개요

폰 노이만 구조의 핵심: 모든 프로그램과 데이터는 반드시 기억장치(DRAM)에 올라와야만 CPU가 꺼내어 일할 수 있습니다.

공장으로 이해하는 컴퓨터 내부 시스템

창고에서 작업대까지, 데이터가 이동하고 처리되는 과정

1. 보조기억장치 (SSD/HDD)

거대한 물류 창고

모든 자재(파일·프로그램)를 보관하는 거대한 공간. 용량은 크지만 너무 멀어서 직접 가지러 가기엔 한세월이 걸립니다.

용량: 매우 큼 속도: 매우 느림
2. 시스템 버스 (Bus)

고속 컨베이어 벨트

창고에 있는 자재를 작업대 옆 선반까지 실어 나르는 데이터 이동 통로입니다.

역할: 데이터 운반 특징: 병목 주의
3. 주기억장치 (DRAM)

작업대 바로 옆 선반

지금 당장 조립할 일감을 올려두는 임시 선반. 손만 뻗으면 닿을 만큼 초고속이며, 퇴근(전원 OFF)하면 깔끔히 비워집니다.

속도: 초고속 성질: 휘발성(임시)
4. 중앙처리장치 (CPU)

숙련된 작업자

선반(DRAM)에 놓인 일감을 빛의 속도로 집어 조립하고 결과를 만들어내는 공장의 핵심 일꾼입니다.

처리: 초고속 연산 조건: 선반이 핵심

선반(DRAM) 크기에 따른 작업 효율 비교

버튼을 눌러 선반이 부족할 때와 충분할 때의 속도 차이를 직접 확인해 보세요.

병목 현상

선반(DRAM)이 작을 때

  • • 선반에 일감을 몇 개 올려두면 금방 꽉 찹니다.
  • • 새 일감을 가져오려면 기존 일감을 치우고 멀리 있는 창고(SSD)까지 왕복해야 합니다.
  • • 작업자(CPU)는 일감이 올 때까지 멍하니 기다리게 되어 전체 속도가 느려집니다.
최적 상태

선반(DRAM)이 충분할 때

  • • 필요한 일감을 선반에 넉넉히 미리 올려둘 수 있습니다.
  • • 창고(SSD)에 갈 필요 없이 선반에서 바로바로 집어 초고속 처리합니다.
  • • 다중 작업(멀티태스킹)을 해도 버벅임 없이 쾌적합니다.

Summary

“DRAM은 CPU가 가장 빠르게 일할 수 있도록 당장 필요한 일감을 올려두는 작업대 바로 옆 선반이다.”

CPU와 DRAM의 대화 언어: 0과 1

문자가 없던 잉카 문명의 '매듭'처럼, 컴퓨터는 '전기 신호의 켜짐/꺼짐'으로 대화합니다.

전원과 전구만 연결하면 불이 계속 켜져(1) 있을 뿐, 원하는 대로 0과 1을 바꿀 수 없습니다.

상태: 제어 불가 (항상 1 고정) 회로 위 스위치를 눌러 전류를 통제해 보세요
1단계: 전구만 있을 때

항상 '1'만 나오는 고장 난 신호등

전선에 전구만 연결하면 전기가 계속 흘러 무조건 1(켜짐) 상태만 유지됩니다. 0을 만들 수 없으니 글자나 숫자를 표현할 수 없습니다.

2단계: 스위치(트랜지스터) 추가

비로소 '1'과 '0'을 자유롭게 표현!

중간에 스위치(트랜지스터)를 달아 전기 흐름을 열고 닫을 수 있게 되면, 우리가 원할 때 정확히 1(ON)과 0(OFF)을 만들어낼 수 있습니다.

데이터를 '저장'하려면 커패시터가 필요하다

스위치만으로는 스위치를 끄는 순간 1이 사라집니다. 전기를 담아두는 초고속 물탱크(커패시터)가 핵심입니다.

커패시터 없음: 스위치를 끄면 데이터가 즉시 날아감!
현재 기억된 값: 1
문제점

스위치를 끄면 데이터가 증발!

전기를 담아둘 그릇이 없으면, 스위치를 여는(OFF) 즉시 전류가 끊겨 방금 입력한 '1'이라는 정보가 사라집니다.

이제 진짜 DRAM 내부로 들어가 볼까요?

수백억 개의 데이터 방(1T1C)을 이루는 4가지 핵심 구조를 아주 쉽게 알아봅시다.

절연체 벽으로 전하를 가둠
③ 데이터 도로
Word & Bit Line

④ 누설 방지 담장

DRAM의 스위치: MOSFET (NMOS)

평소엔 중간이 꽉 막혀 있지만, 게이트(문)에 전압을 주면 '전자 다리(채널)'가 생겨 전기가 흐릅니다.

상태: 차단됨 (다리 없음 · 전기 안 흐름) 그림의 '게이트(Gate)'를 직접 클릭해도 바뀝니다!
평소 상태 (게이트 OFF)

강물이 가로막은 끊어진 다리

왼쪽(N+)과 오른쪽(N+) 사이에 성격이 다른 땅(P형 기판)이 가로막고 있어서 전자들이 건너가지 못합니다.

전압 인가 (게이트 ON)

자석처럼 전자를 끌어당겨 다리 완성!

게이트에 (+) 전압을 걸면 땅속의 (-) 전자들이 게이트 아래로 모여들며 다리(채널)를 만듭니다. 이 다리를 통해 전기가 슝 통과합니다!

DRAM의 기억 창고: 커패시터 (금속-절연체-금속)

전기가 통하지 않는 절연체(벽)를 사이에 두고 (+)와 (-)가 서로 끌어당기는 힘으로 전기를 저장합니다.

MIM 구조 (Metal - Insulator - Metal) 현재 상태: 충전 완료 (1)
중간에 절연체(벽)가 막고 있어서 (+)와 (-)가 합쳐지지 않고, 서로 마주 보며 꽉 붙잡힌 채 저장됩니다.
실생활 속 같은 원리

풍선으로 머리를 문지를 때!


서로 끌어당김! + + +

풍선(-)과 머리카락(+)이 공기를 사이에 두고 떨어져 있어도 서로 달라붙듯, 커패시터도 반대 전기끼리 끌어당기는 힘을 이용합니다.

데이터가 나가는 길: Word Line & Bit Line

가로줄(Word Line)이 스위치 문을 열어주면, 저장된 데이터가 세로 고속도로(Bit Line)를 타고 CPU로 나갑니다.

대기 중: 커패시터에 데이터 '1'이 보관되어 있습니다. ↑ CPU 방향 (데이터 출력)
가로줄: Word Line (WL)

"몇 번째 줄 문 열어!" 신호선

수많은 스위치의 게이트(손잡이)를 가로로 한 줄에 엮은 선입니다. WL에 전기가 들어오면 그 줄의 스위치 문이 일제히 열립니다.

세로줄: Bit Line (BL)

데이터가 CPU로 달리는 고속도로

스위치 문이 열리면 커패시터 안에 있던 1 또는 0의 전기 신호가 Bit Line을 타고 빠져나가 CPU로 전달됩니다.

옆집으로 전기가 새지 않게: STI (소자 분리막)

수백억 개 스위치를 다닥다닥 붙이면 바닥으로 전기가 샙니다. 땅을 파고 절연 벽(STI)을 세워 차단합니다.

위험: 실리콘 바닥을 통해 옆집 셀 B로 전기가 새어 나감! Shallow Trench Isolation (얕은 도랑 절연)
집적도가 높아지며 생긴 문제

벽 없는 원룸촌의 소음·전기 간섭

수백억 개의 스위치를 좁은 땅에 붙여서 짓다 보니, 한쪽에서 흐르던 전기가 실리콘 바닥을 타고 옆 스위치로 새어 들어가 0이 1로 바뀌는 오류가 생깁니다.

해결책: STI 공법

땅을 깊게 파서 절연체 벽을 채움

스위치와 스위치 사이에 얕은 도랑(Trench)을 파고 전기가 통하지 않는 절연 물질을 채워 넣어 각 방을 완벽히 독립시킵니다.

종합: 한눈에 보는 DRAM 버티컬(수직) 구조

데이터 이동 경로: 커패시터(저장) → Word Line 채널(통과) → Bit Line(전송)

버튼을 눌러 저장된 데이터 '1'이 CPU로 올라가는 전체 과정을 확인하세요! 1T1C Vertical Cross-Section
1. 커패시터 (위로 솟은 기둥)

좁은 면적에 많은 전기를 담기 위해 위로 높게 쌓아 1과 0을 저장합니다.

2. Word Line & MOSFET (중간 문)

Word Line에 신호가 들어오면 바닥에 전자 다리(채널)가 열립니다.

3. Bit Line (세로 고속도로)

다리를 건넌 데이터가 Bit Line을 타고 CPU로 즉시 전달됩니다.

4. STI (양쪽 절연 담장)

옆 방의 셀들과 전기가 섞이지 않도록 물리적으로 완벽 차단합니다.

스위치의 모양이 달라졌다: Buried Gate

Gate를 실리콘 표면 아래에 묻어, 전류가 지나가는 길을 더 길게 만듭니다.

기존 평면형 Gate
채널이 짧아지면 스위치를 껐을 때도 전류를 완전히 막기 어려워질 수 있습니다.
Buried Gate
채널 경로를 길게 확보해 짧은 채널 효과(SCE)를 줄이는 데 도움을 줍니다.
핵심: Gate가 땅속에 묻혔을 뿐, 스위치의 기본 동작 원리는 동일합니다.

커패시터는 원통형으로 세워진다

작은 바닥 면적 안에서 더 넓은 저장 공간을 확보하기 위한 입체 구조입니다.

실제 커패시터를 옆에서 본 모습
왜 원통형일까?

칩의 바닥 면적은 좁아도, 위로 높게 세우고 안쪽까지 활용하면 전극의 표면적을 크게 만들 수 있습니다.

잘라서 단면을 보면?

앞에서 배운 MIM 커패시터 원리와 같습니다. 모양만 입체적으로 바뀐 것입니다.

더 넓은 표면적 = 더 많은 전하 저장

Bit Line은 여러 셀이 함께 사용한다

한 번에 선택되는 Word Line은 하나이므로, 여러 셀이 하나의 Bit Line을 공유할 수 있습니다.

공유하지 않는다면
셀마다 별도의 배선이 필요해 배선 공간이 커집니다.
하나의 Bit Line을 공유하면
Word Line이 번갈아 선택되고, 데이터는 같은 Bit Line을 따라 이동합니다.
공유 구조: 하나의 Bit Line에 두 셀이 연결되어 있습니다.
실제 DRAM에서는 하나의 Bit Line에 더 많은 셀이 연결됩니다. 그림은 원리를 보여주기 위한 단순화된 예시입니다.

끊어진 층과 층을 이어주는 Contact

Buried Gate는 실리콘 안쪽에 묻혀 있고, Gate Oxide와 채널은 Gate의 옆면과 바닥을 따라 형성됩니다.

단면 개념도 · Contact와 Buried Gate의 연결 관계
왜 필요할까?

층간 절연막은 전기가 흐르지 않도록 막습니다. Bit Line과 트랜지스터, Capacitor와 트랜지스터를 연결할 위치에는 별도의 전도 경로가 필요합니다.

Contact의 역할

절연막에 작은 구멍을 만들고 도전 물질로 채워, Bit Line과 N+ Si 및 Storage Node와 N+ Si를 각각 연결합니다.

기억할 점

STI는 절연, Contact는 연결, Gate는 채널 제어를 담당합니다.

작은 1T1C가 모여 거대한 DRAM이 된다

저장하고, 선택하고, 연결하고, 데이터를 전달하는 구조

실제 DRAM 셀을 단순화한 수직 단면 · 구조 중심
Capacitor

데이터 0과 1을 전하로 저장

Buried Gate + Word Line

U자형 채널을 제어해 셀을 선택

Bit Line

데이터가 오가는 통로

Contact

N+ 확산층과 배선을 연결

STI

깊은 절연막으로 이웃 셀과 분리

DRAM은 1T1C라는 단순한 셀을 수없이 모아 데이터를 저장하고, 메모리 시스템을 통해 CPU와 주고받는 현대 전자기기의 핵심 메모리입니다.
